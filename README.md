# awesome-free-ai-tools
> Free AI tools that aren't chatbots. Curated, simple, and free to use — one line per entry.
- [Remove.bg](https://www.remove.bg/) — Remove backgrounds automatically
- [Upscayl](https://upscayl.org/) — Free, open-source image upscaler
- [Leonardo](https://leonardo.ai/) — Generate images on a daily free plan
- [CapCut](https://www.capcut.com/) — Video editor with auto-captions
- [ElevenLabs](https://elevenlabs.io/) — Text-to-speech with a free tier
- [Suno](https://suno.com/) — Make a song from a text prompt
- [Perplexity](https://www.perplexity.ai/) — AI answers with sources, free to use
- [NotebookLM](https://notebooklm.google.com/) — Chat with your own documents, free
